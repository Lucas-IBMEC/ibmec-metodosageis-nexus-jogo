1O desafio final

Agora não tem carta: cada lado escreve um prompt para este problema da escola, com as 3 partes das cartas. Vocês têm 3 minutos.

As 3 partes do prompt

  • Persona Quem a IA vai ser? Alguém que entende do problema. “Você é…”
  • Contexto Onde é, o que está acontecendo e um detalhe. “Na nossa escola…”
  • Formato Como a resposta deve chegar, e para quem. “Responda em formato de lista com 3 passos.”

O pedido é resolver o problema: “Crie…”, “Explique…”.

2A nota de cada prompt

Cada lado lê o prompt em voz alta e você digita aqui. O aplicativo dá a nota de 1 a 4, sem internet, com as mesmas regras das cartas.

A nota vem das palavras do prompt, como os números escondidos das cartas: o aplicativo mostra o porquê de cada parte, e a palavra final é do professor. Com internet, dá para ver a IA de verdade: cole o melhor prompt num assistente de IA e leia a resposta em voz alta.
